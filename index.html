Meus projetos

Sistema de Alterações de Preços

Sistema open source desenvolvido para automatizar a comparação de tabelas de preços, identificando aumentos, reduções, novos produtos e alterações de estoque. Permite importar arquivos, pesquisar produtos por NCE ou nome e gerar relatórios em PDF, tornando a conferência de preços mais rápida e eficiente. Tecnologias e arquitetura: desenvolvido com HTML5, CSS3 e JavaScript puro (Vanilla JS), sem dependência de frameworks. Utiliza JavaScript Modules (ES Modules) para modularização e separação de responsabilidades, além de uma arquitetura CSS organizada em arquivos específicos, facilitando a manutenção, reutilização e escalabilidade do código.

Sistema de Gestão de Estoque

Sistema web desenvolvido para facilitar o gerenciamento de estoque de oficinas de motos. Permite cadastrar produtos, controlar entradas e saídas de peças, acompanhar movimentações e identificar automaticamente itens com estoque baixo. Possui autenticação de usuários, painel administrativo com indicadores e interface responsiva para computadores e dispositivos móveis. Tecnologias utilizadas: HTML5, CSS3, JavaScript puro (Vanilla JavaScript), Supabase (Backend as a Service), PostgreSQL e SQL.
